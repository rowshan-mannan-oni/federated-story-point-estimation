What the site knows

Every figure the walk-through can show, listed with where it came from and how it was worked out. No number is typed into a page by hand: they are all produced by one script that reads the project’s own data and results.

Re-run python site/tools/extract_facts.py after any change to the data or the results, and the whole site updates. If a figure is missing here, it is missing on the site too — shown as a dash, never as a plausible zero.
