The parts bin

Every control and readout the walk-through is built from. Nothing here explains the thesis — this is the drawer the tools live in, kept so the stops stay consistent and so each piece can be checked on its own.

Everything below works with the mouse and the keyboard: tab to a control, then use the arrow keys. Try it — a knob that only responds to dragging is a knob half the readers of this site could not use.
