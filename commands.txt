# ==========================================================
# Federated Story Point Estimation - Command Runbook
# ==========================================================
# Run these from PowerShell. Either activate the venv first, or replace
# `python` with the full interpreter path:
#     & "d:/Federated Learning using DL/.venv/Scripts/python.exe"
# All commands assume the current directory is the project root.
#
# Data dir  : one CSV/XLSX per project, INCLUDING the warm-start project
#             (lsstcorp.csv). The warm-start project is pre-trained on and
#             then excluded from the FL client pool; every other project is
#             one FL client.
# bert-tiny : DEV/SMOKE encoder only. Never interpret its accuracy — use it
#             to check plumbing, then switch to a real encoder for results.
# Seeds     : --seed keeps a run reproducible. Use 42..51 for the 10-seed
#             statistical runs (run_experiments.py + compute_statistics.py).
#
# ---- Condition labels (auto-derived, no extra flag) --------------------
#   --prox-mu 0        -> "FedAvg"          --prox-mu >0 -> "FedProx (mu=X)"
#   --personalized-head-> appends " + P-head" (e.g. "FedProx (mu=0.01) + P-head")
#   The label appears in console output, results/summary.md, and
#   results/config.json ("federated_condition").
#
# ---- Head / loss (gap #12) ---------------------------------------------
#   --head-type ce     5-logit softmax + class-weighted CrossEntropy
#                      (default; baseline/ablation arm).
#   --head-type corn   4-logit CORN ordinal head + corn_loss (num_classes-1
#                      threshold logits). Use for the final ordinal results;
#                      expect it to move MAE / Cohen's Kappa more than macro-F1.
#
# ---- Personalized head, FedSP-PEFT-P (gap #11) -------------------------
#   --personalized-head  Head stays LOCAL per client (never aggregated); only
#                        LoRA-B + embeddings are federated. There is NO pooled
#                        "global" test metric — report per-project + mean.
#                        Artifact layout: <save-dir>/federated/{shared_state.pt,
#                        heads/<project>.pt}.
#   --generic-head       Personalized mode only: also save
#                        federated/generic_head.pt (one-way weighted average of
#                        client heads) for new-client onboarding init. Never
#                        pushed back to participants.
#
# ---- Checkpoint / resume (gap #13) -------------------------------------
#   --checkpoint-every N Checkpoint frequency (0 = off). Unit = global ROUNDS
#                        for federated, EPOCHS for centralized & local-only.
#   --checkpoint-keep K  Numbered checkpoints kept (default 2); latest/ and
#                        best/ are always kept on top. Layout:
#                        <save-dir>/checkpoints/{federated|centralized|
#                        local_only/<project>}/{latest,best,round_<k>|epoch_<k>}.
#   --resume             Auto-detect and resume from the latest checkpoint under
#                        <save-dir>/checkpoints/ (re-pass the SAME command +
#                        --resume). Resume is bit-reproducible.
#   --resume-from <dir>  Resume the federated phase from an explicit checkpoint dir.
#   NOTE: checkpoints are trainable-only (never the frozen backbone), so a
#   resume re-runs warm-start (cheap; also keeps LoRA-A reproducible).
#
# ---- Leave-one-project-out onboarding (gap #14) -----------------------
#   --holdout-project <name>  Exclude a project from the FL pool entirely
#                             (train/val/test) so it can be onboarded later via
#                             run_lopo.py. Cannot be the warm-start source.
#
# ---- Encoder target modules --------------------------------------------
#   query value  -> BERT/RoBERTa family (prajjwal1/bert-tiny, distilroberta-base,
#                   microsoft/codebert-base). This is the default.
#   q_lin v_lin  -> distilbert-base-uncased. Pass --lora-target-modules q_lin v_lin.
#
# ---- Warm-start ablation (gap #7) --------------------------------------
#   --run-no-warmstart-fl  Also train a second federated model from random init
#                          (same per-round client selection). Roughly doubles
#                          federated time. Extra outputs:
#                          federated_no_warmstart_per_project.json and the
#                          <save-dir>/federated_no_warmstart artifact.


# ==========================================================
#  ARGUMENT REFERENCE
# ==========================================================
#
# ---- train_federated_dl.py --------------------------------------------
# Data & splits
#   --data-dir (required, path)         One CSV/XLSX per project (incl. warm-start).
#   --test-size (float, 0.2)            Per-client test fraction; evaluated once.
#   --val-size (float, 0.1)             Per-client validation fraction (round tracking + best-on-val).
#   --split-mode {random, temporal}     random = stratified; temporal = train earliest, val/test latest (gap #9).
#   --holdout-project (str, none)       Exclude one project from the FL pool for LOPO (gap #14).
#
# Model / encoder
#   --model-name (str, prajjwal1/bert-tiny)  HF encoder. bert-tiny = dev only.
#   --max-length (int, 128)             Token cap for title+description (try 256 ablation).
#   --freeze-encoder (flag)             Freeze backbone (only meaningful with --no-lora).
#
# Head / loss
#   --head-type {ce, corn} (ce)         CE softmax head vs CORN ordinal head (gap #12).
#
# LoRA / FFA-LoRA
#   --no-lora (flag)                    Disable LoRA adapters.
#   --no-ffa-lora (flag)                Train+aggregate both A and B (reintroduces aggregation error; RQ3 ablation).
#   --lora-r (int, 8) / --lora-alpha (int, 16) / --lora-dropout (float, 0.05)
#   --lora-target-modules (list, query value)  q_lin v_lin for DistilBERT.
#
# Federated optimization
#   --rounds (int, 8)                   Global FL rounds.
#   --local-epochs (int, 1)             Local epochs per selected client per round.
#   --clients-per-round-fraction/--fraction (float, 1.0)  Client sampling fraction (0,1].
#   --local-sample-ratio-per-epoch (float, 1.0)           Per-client local subsample (0,1].
#   --sample-with-replacement (flag)
#   --prox-mu (float, 0.01)             FedProx strength over aggregatable params; 0 -> FedAvg.
#   --personalized-head (flag)          Keep head local per client (gap #11).
#   --generic-head (flag)               Personalized only: also save averaged generic_head.pt.
#   --lr (float, 2e-5) / --weight-decay (float, 1e-4)
#
# Warm-start
#   --warmstart-project (str, lsstcorp) / --warmstart-val-size (0.15)
#   --warmstart-epochs (10) / --warmstart-patience (3) / --warmstart-lr (2e-5)
#   --run-no-warmstart-fl (flag)        Warm-start ablation (gap #7).
#
# Baselines / toggles
#   --skip-centralized (flag) / --skip-local-only (flag)
#
# Checkpoint / resume (gap #13)
#   --checkpoint-every (int, 0) / --checkpoint-keep (int, 2)
#   --resume (flag) / --resume-from (str, none)
#
# Output / reproducibility / device
#   --seed (int, 42) / --device {cuda, cpu} / --batch-size (int, 16)
#   --central-log-every (int, 1)
#   --save-dir (str, artifacts)         Artifacts under <save-dir>/{warmstart,centralized,
#                                       local_only,federated,...}; metrics under <save-dir>/results/;
#                                       checkpoints under <save-dir>/checkpoints/.
#
# ---- predict_saved_model.py -------------------------------------------
#   --artifact-dir (required)           A saved model folder (e.g. artifacts/federated).
#   --data-dir (required)               Files to score (metrics printed if story_point present).
#   --head-project (str, none)          Personalized artifact: overlay heads/<name>.pt.
#   --generic-head (flag)               Personalized artifact: use generic_head.pt instead.
#   --batch-size (16) / --device / --out-csv (predictions.csv)
#
# ---- run_lopo.py (gap #14) --------------------------------------------
#   --artifact-dir (required)           Federated artifact trained WITH the project held out.
#   --data-dir (required)               Full dataset dir (holdout project must be present).
#   --holdout-project (required)        The project to onboard.
#   --head-init {generic, random} (generic)  Personalized artifact head init (ignored for shared).
#   --budgets (str, "0,10,25,50,100")   Adaptation budgets (earliest issues).
#   --test-size (0.2) / --adapt-epochs (30) / --adapt-lr (1e-3) / --batch-size (32)
#   --device / --seed / --out-dir (results)  Writes lopo_<project>_<condition>.json.
#
# ---- compare_lopo.py (gap #14) ----------------------------------------
#   --results-dir (results) / --glob ("lopo_*.json") / --metrics (accuracy,macro_f1,mae,cohen_kappa)
#   --out (<results-dir>/lopo_comparison.csv)  Tidy LONG CSV for the crossover plot.
#
# ---- run_experiments.py (gap #4) / compute_statistics.py (gap #5) -------
#   run_experiments: --seeds (42-51) / --prox-mu (0.01) / --results-root (experiments)
#                    / --skip-fedavg / --force / --dry-run. Any other flag (incl. --head-type,
#                    --personalized-head, --checkpoint-*) is forwarded verbatim to BOTH runs.
#   compute_statistics: --experiments-root / --seeds / --metric {macro_f1,accuracy,cohen_kappa,mae}
#                    / --alpha (0.05) / --out-dir.

# 9) FINAL RESULTS RUN — 24 GB VRAM, no time limit (addresses RQ1-RQ4)
# ==========================================================
# Encoder: distilroberta-base @ max-length 256 (CLAUDE.md's final encoder;
#          RoBERTa arch -> default query/value target modules). CORN ordinal
#          head. 10 seeds (42-51), 20 rounds, full participation.

#          LoRA (only LoRA-B + head + embeddings train). 24 GB can usually

#          no OOM in the first round.

#          --resume) — finished seed/condition pairs are skipped and an
#          interrupted one continues from its last completed round/epoch/client.
#
# DAILY WORKFLOW (short lab sessions): just Ctrl-C (or power off) when your
# time is up, and next day re-run the EXACT same command. On resume:
#   - warm-start is REUSED from cache (not retrained) — no re-paying it daily;
#   - centralized skips finished epochs, local-only skips finished clients,
#     federated continues from its last round. Resume is bit-reproducible.

# --- RQ4 onboarding (cold-start crossover): run the LOPO block in section 7
#     with the SAME encoder/flags, holding out a mid-sized project such as
#     MongoDB_Core_Server (711 rows) or Moodle (978 rows) — NOT Lsstcorp.
#
# NOTES
# - Run A first: it produces the majority/local-only/centralized baselines used
#   across RQ1-RQ3. Run B (--skip-baselines) trains only the federated
#   (personalized) part and is compared against run A's seed-matched baselines.
# - compute_statistics pairs FedProx vs {Local-only, Centralized, FedAvg} within
#   one root. The shared-vs-personalized (RQ4) comparison is done across the two
#   roots' federated_per_project.json (per-project; personalized mode has no
#   pooled "global" row by design — report per-project + mean/median).
# - Warm-start is cached per seed/condition: the first time a run trains it, the
#   state + post-warm-start RNG are saved under <save-dir>/warmstart/; any later
#   --resume of that run loads them instead of retraining (bit-reproducible).
# - If 24 GB is tight at max-length 256, drop to --max-length 128 (p90 token
#   length is 164) before lowering the batch size.
